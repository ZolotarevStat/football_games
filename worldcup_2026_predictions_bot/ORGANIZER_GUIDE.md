# Инструкция организатора турнира

## Доступ участников

На период турнира бот работает в открытом режиме:

```text
OPEN_REGISTRATION_ENABLED=true
```

Это значит, что участник может написать боту в личку и начать пользоваться без invite/PIN. Такой режим выбран осознанно: бот приватный, аудитория ограничена турнирным чатом, риск спама/DoS для MVP критически низкий.

Если позже понадобится закрыть доступ, можно вернуться к invite/PIN или allowlist, но это не текущий рабочий сценарий турнира.

## Где вести результаты

Результаты матчей заносятся вручную в Google Sheets, лист `results`.

Одна строка = один матч.

```text
match_id | actual_score | status | goals | assists | own_goals | updated_at
```

Пример:

```text
MexSAf | 2-1 | final | Рауль Хименес, Икраам Рейнерс, Рауль Хименес | Икраам Рейнерс | | 2026-06-12T01:00:00+03:00
```

Поля:

- `match_id`: код матча из листа `matches`, например `MexSAf`.
- `actual_score`: итоговый счет в формате `2-1`.
- `status`: `final` для сыгранного матча.
- `goals`: авторы голов через запятую. Источник для сверки: sports.ru.
- `assists`: официальные ассисты через запятую. Источник для сверки: sports.ru.
- `own_goals`: авторы автоголов через запятую.
- `updated_at`: время заполнения, можно оставить пустым, если не важно для аудита.

Если игрок забил дважды, его имя нужно написать дважды:

```text
Рауль Хименес, Рауль Хименес
```

## Отмененные и технические матчи

Такие матчи не должны влиять на таблицу.

Для них укажите `status`:

- `cancelled`: матч отменен;
- `technical`: технический результат;
- `void`: результат не учитывается.

Если `status` равен `cancelled`, `technical` или `void`, бот игнорирует строку при пересчете.

## Нейминг игроков

Имена авторов голов, ассистов и автоголов нужно писать ровно как в листе `players`, колонка `player_name_ru`.

Правильно:

```text
Рауль Хименес
Икраам Рейнерс
Килиан Мбаппе
```

Нежелательно:

```text
Хименес
Raul Jimenez
Р. Хименес
Mbappe
```

Почему так: scoring матчится по точной строке. Если имя отличается от `player_name_ru`, очки за автора Г+П не начислятся.

Практичный флоу:

1. Откройте лист `players`.
2. Отфильтруйте нужную команду.
3. Скопируйте имя из `player_name_ru`.
4. Вставьте его в `goals`, `assists` или `own_goals`.

## Как пересчитать очки

После заполнения `results` отправьте боту админскую команду:

```text
/score MATCH_ID
```

Пример:

```text
/score MexSAf
```

Для пересчета всех заполненных результатов:

```text
/score all
```

Бот обновит листы:

- `scoring`: очки по каждому участнику и матчу;
- `leaderboard`: итоговая таблица.
- `leaderboard_by_total`: сортировка по общим очкам;
- `leaderboard_by_score`: сортировка по очкам за счета;
- `leaderboard_by_goals`: сортировка по очкам за голы выбранных игроков;
- `leaderboard_by_assists`: сортировка по очкам за пасы выбранных игроков;
- `match_author_picks`: каких игроков чаще всего выбирали по каждому матчу;
- `match_first_score_belief`: в чью победу или ничью чаще верили первым счетом.

`leaderboard` записывается как удобная витрина с колонками:
`№`, `Имя`, `№ матчей`, `Счёт`, `Голы`, `Ассисты`, `Итого`, `Группа`, `Плей-офф`.
После пересчета бот обновляет фильтр листа на фактический диапазон строк, центрирует таблицу, подбирает ширину колонок и подсвечивает зеленым лидеров по числовым колонкам.

## Уведомления участникам

Основной флоу напоминаний автоматический: worker каждый день в 12:00 МСК проверяет матчи ближайших 24 часов и пишет в личку участникам, которые уже отправляли хотя бы один прогноз.

Ручная команда `/remind MATCH_ID` не нужна для текущего MVP. Если автоматические напоминания окажутся недостаточными, её можно добавить позже как админскую команду.

## Правила начисления очков

Группа:

- точный счет: 12, 10, 8, 7, 6, 5, 4 очка за варианты 1-7;
- гол выбранного игрока: 4;
- ассист выбранного игрока: 2.

Плей-офф:

```text
Стадия                 Счета 1-7                 Гол  Пас
1/16                   15,12,10,8,7,6,5           4    2
1/8                    19,15,12,10,8,7,6          6    3
1/4 и матч за 3 место  21,17,14,12,10,9,8         8    4
1/2                    23,19,16,14,12,11,10       10   5
Финал                  25,21,18,16,14,13,12       12   6
```

Автоголы не дают очки выбранному игроку. Отмененные матчи и технические результаты не учитываются.

При равенстве total points порядок такой:

1. больше очков в финале;
2. больше очков в матче за 3 место;
3. больше очков в 1/2;
4. больше очков в 1/4;
5. дальше 1/8, 1/16, группа.

## Как проверить сдачу прогнозов

До дедлайна или сразу после него отправьте:

```text
/status
```

Бот покажет список открытых матчей кнопками. Быстрый вариант с ID тоже поддерживается:

```text
/status MexSAf
```

Бот покажет:

- сколько активных участников сдали прогноз;
- кто еще не сдал;
- дедлайн матча.

## Как посмотреть агрегаты прогнозов по матчу

После того как участники начали сдавать прогнозы, отправьте:

```text
/insights
```

Бот покажет список матчей с прогнозами кнопками. Быстрый вариант с ID тоже поддерживается:

```text
/insights MexSAf
```

Бот покажет:

- самый популярный первый счет и его долю;
- самых популярных авторов Г+П по каждой команде;
- доли исходов по первым счетам;
- всех выбранных игроков в группировке по команде и количество участников, выбравших каждого игрока.

## Как опубликовать таблицу

После проверки `leaderboard` отправьте:

```text
/leaderboard
```

Бот отправит таблицу в турнирный чат.

## Как опубликовать прогнозы после дедлайна

После дедлайна матча отправьте:

```text
/publish
```

Бот покажет матчи после дедлайна, где есть прогнозы. Быстрый вариант с ID тоже поддерживается:

```text
/publish MexSAf
```

Бот отправит в турнирный чат сообщение в формате:

```text
🔒 Прогнозы закрыты: Мексика - ЮАР
Дедлайн: 11.06 21:55 МСК

👤 Игрок 1
Счета: 1-0, 1-1, 2-0, 0-0, 2-1, 1-2, 0-1
Рауль Хименес, Икраам Рейнерс
```

Публикация до дедлайна блокируется сервером.

## Почему не вводим результаты через бота в MVP

Для MVP основной флоу через Google Sheets надежнее.

Причины:

- в одном матче может быть много голов, ассистов и повторов одного игрока;
- нужно аккуратно различать голы, ассисты и автоголы;
- имена игроков должны совпадать с `player_name_ru`;
- исправлять ошибку в таблице проще, чем проходить длинный админский сценарий в Telegram;
- Google Sheets оставляет результат видимым и проверяемым до публикации таблицы.

Админский ввод через бота можно добавить позже, если ручное заполнение `results` станет главным bottleneck. Для текущего MVP бот отвечает за пересчет и публикацию, а Google Sheets остается источником правды по результатам.

## Быстрый чек после матча

1. Заполнить строку в `results`.
2. Проверить, что все имена игроков скопированы из `players.player_name_ru`.
3. Отправить `/score MATCH_ID`.
4. Проверить строки в `scoring` и `leaderboard`.
5. Отправить `/leaderboard`, если таблица выглядит корректно.
